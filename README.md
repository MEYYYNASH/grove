# Meu Music

A premium native Android music player built with Kotlin, Jetpack Compose, Material 3, Room, Media3 ExoPlayer, and GitHub Releases self-updates.

## Features
- **Soft Liquid Glass UI**: Translucent glass cards, glowing color themes, smooth spring animations, and bottom navigation pill.
- **Robust Audio Playback**: Media3 ExoPlayer + MediaSessionService supporting background play, notification controls, lock screen controls, and audio focus.
- **Local & Streaming Music**: Pre-loaded with royalty-free tracks, playlists, liked songs, and offline download manager.
- **YouTube Music Search & Stream**: Search and stream online tracks instantly with one-tap offline download.
- **In-App Self Updates**: Automatic checking against GitHub Releases latest version with download progress, SHA-256 verification, and APK installation.
- **GitHub Actions Release Pipeline**: Automated build and publishing workflow via `.github/workflows/release.yml`.

## How to Build & Run
1. Open the project in Android Studio (Girard / Ladybug or newer).
2. Sync Gradle and run on an Android 10+ device or emulator.
3. Enjoy the premium music player experience!
